# 🌐 Networking Fundamentals

This section covers the basic concepts of computer networking and how devices communicate with each other.

## 📌 What is a Computer Network?

A computer network is a group of interconnected devices that communicate and share data and resources with each other.

Examples:

- Computers
- Smartphones
- Servers
- Routers
- Switches
- Printers
- IoT devices

## 🔗 Why Do We Need Networks?

Networks allow devices to:

- Share information
- Access the Internet
- Share resources
- Communicate with other devices
- Access remote services
- Exchange files and data

## 🏠 Types of Networks

### LAN — Local Area Network

A network covering a small geographical area such as a home, classroom, office, or building.

### WAN — Wide Area Network

A network covering a large geographical area.

The Internet is the largest example of a WAN.

### MAN — Metropolitan Area Network

A network that covers a city or large campus.

### PAN — Personal Area Network

A small network around an individual, such as devices connected through Bluetooth.

## 🖥️ Common Network Devices

| Device | Purpose |
|---|---|
| Router | Connects different networks |
| Switch | Connects devices within a network |
| Hub | Broadcasts data to connected devices |
| Access Point | Provides wireless network access |
| Firewall | Controls and filters network traffic |
| Modem | Connects a network to an Internet service |

## 📡 Basic Networking Terms

### IP Address

A logical address used to identify a device on a network.

### MAC Address

A hardware-level address associated with a network interface.

### Protocol

A set of rules that defines how devices communicate.

Examples include:

- TCP
- UDP
- HTTP
- HTTPS
- DNS
- DHCP

### Port

A logical communication endpoint used by network services.

Examples:

- HTTP — 80
- HTTPS — 443
- DNS — 53
- SSH — 22
