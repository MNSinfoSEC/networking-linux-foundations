# 🐧 Linux Fundamentals

This section covers the basic concepts of Linux and introduces the command-line environment used widely in system administration and cybersecurity.

## 📌 What is Linux?

Linux is an open-source operating system kernel used in many operating systems and environments.

Linux-based systems are widely used in:

- Servers
- Cloud infrastructure
- Networking devices
- Cybersecurity
- Development environments
- Embedded systems

## 🧠 Why is Linux Important in Cybersecurity?

Linux is an important foundation for cybersecurity because security professionals frequently work with:

- Servers
- Security tools
- Network services
- System logs
- Processes
- Permissions
- Command-line tools

Understanding Linux makes it easier to investigate systems and perform security-related tasks.

## 🖥️ Linux Distributions

A Linux distribution combines the Linux kernel with software and tools.

Examples include:

- Ubuntu
- Debian
- Fedora
- Arch Linux
- Kali Linux
- Linux Mint

## 💻 Command Line

Linux can be managed through a graphical interface, but cybersecurity professionals frequently use the command line.

The terminal allows users to:

- Navigate the filesystem
- Create and manage files
- Manage processes
- Configure systems
- Inspect logs
- Perform network troubleshooting

## 🛠️ Basic Commands

| Command | Purpose |
|---|---|
| pwd | Shows the current directory |
| ls | Lists files and directories |
| cd | Changes directory |
| mkdir | Creates a directory |
| touch | Creates a file |
| cp | Copies files or directories |
| mv | Moves or renames files |
| rm | Removes files or directories |
| cat | Displays file contents |
| clear | Clears the terminal |
