# 🌍 IPv4 & IPv6

Internet Protocol (IP) is responsible for identifying devices and enabling communication across networks.

There are two major versions of IP:

- **IPv4** (32-bit)
- **IPv6** (128-bit)

---

## 📘 What is IPv4?

IPv4 is the most widely used Internet Protocol version.

Example:

192.168.1.25

### Features

- 32-bit address
- Four decimal octets
- Range: 0–255 per octet
- Approximately 4.3 billion addresses

Example format:

192.168.1.10

---

## 🌐 What is IPv6?

IPv6 was introduced to solve IPv4 address exhaustion.

Example:

2001:db8:85a3::8a2e:370:7334

### Features

- 128-bit address
- Written in hexadecimal
- Much larger address space
- Better support for modern Internet infrastructure

---

## 🔄 IPv4 vs IPv6

| Feature | IPv4 | IPv6 |
|---|---|---|
| Address size | 32-bit | 128-bit |
| Notation | Decimal | Hexadecimal |
| Example | 192.168.1.10 | 2001:db8::1 |
| Address space | ~4.3 billion | 340 undecillion+ |

---

## 🏠 Private IPv4 Ranges

| Range | Purpose |
|---|---|
| 10.0.0.0/8 | Private network |
| 172.16.0.0/12 | Private network |
| 192.168.0.0/16 | Home and office networks |

Example:

192.168.1.15

---

## 🌍 Public IPv4

Public IP addresses are globally routable and allow communication across the Internet.

Example:

8.8.8.8

---

## 🔐 Why IPv6 Matters

As the number of connected devices continues to grow, IPv6 provides enough addresses for future Internet expansion and modern networking.
